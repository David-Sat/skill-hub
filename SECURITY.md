# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `skill-hub`, please do NOT open a public issue.

Instead, please send an advisory email directly to:
**security@satomi.io** or submit a confidential advisory on GitHub:  
[https://github.com/David-Sat/skill-hub/security/advisories](https://github.com/David-Sat/skill-hub/security/advisories)

All security reports will be acknowledged within 48 hours, and a fix will be published via a patch release.
