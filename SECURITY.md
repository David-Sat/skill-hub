# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability within `skilldesk`, please do NOT open a public issue.

Instead, please send an advisory email directly to:
**security@satomi.io** or submit a confidential advisory on GitHub:  
[https://github.com/David-Sat/skilldesk/security/advisories](https://github.com/David-Sat/skilldesk/security/advisories)

All security reports will be acknowledged within 48 hours, and a fix will be published via a patch release.
